# Pygame Blackjack

A fully functional Blackjack card game simulator built in Python. This project utilizes the Pygame library for rendering. 

## Prerequisites

To run this game, you must have Python installed on your system along with the Pygame library. 

1. If you don't have Python installed, download it from [python.org](https://www.python.org/downloads/).
2. Open your terminal or command prompt and install Pygame via pip:

```bash
pip install pygame
```
*(Mac/Linux users may need to run `pip3 install pygame`)*

## How to Run the Game

1. Clone this repository or download the project files to your local machine.
2. Open your terminal and navigate to the project folder:
```bash
cd path/to/your/blackjack-folder
```
3. Execute the Python file to launch the game window:
```bash
python blackjack.py
```
*(Note: Mac/Linux users may need to run `python3 blackjack.py`)*

## Features
* Standard Blackjack hit/stand mechanics
* Object-oriented card and deck rendering
* Built entirely in Python with Pygame
